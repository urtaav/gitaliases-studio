GitAliases Studio

A free visual tool to create, explain and apply git aliases without memorizing syntax. Pick aliases from a catalog, design how git log looks, list your recent branches, draw commit charts in the terminal and undo mistakes safely. You get commands that work the first time in PowerShell, Bash and zsh, or one .gitaliases file for everything. Available in English and Spanish.

Una herramienta gratuita para crear, entender y aplicar alias de git sin memorizar la sintaxis, en inglés y español.
